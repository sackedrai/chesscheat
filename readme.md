# ChessCheat

English | [Русский](#русский)

## English

ChessCheat is a browser extension that shows the best move in chess.com games using the Stockfish engine.

### Original source

The code is based on [Eugenenoble2005/chesscheat](https://github.com/Eugenenoble2005/chesscheat) (author: Eugenenoble2005). The chess engine is Stockfish.

### What changed vs original

- All developer mentions replaced with **sackedrai**
- Repository links updated (readme, package.json, popup.html)

### Author

**sackedrai**

### Installation

1. Clone the repo:
   ```bash
   git clone https://github.com/sackedrai/chesscheat.git
   ```
2. Open `chrome://extensions` (Chrome) or `about:debugging` (Firefox).
3. Enable Developer mode.
4. Click "Load unpacked" and select the repo folder.

### Warning

This project is for learning purposes. I do not condone or encourage cheating in games. Unfair play may result in your chess.com account being suspended.

## Русский

Расширение для браузера, показывающее лучший ход в шахматных партиях на chess.com с помощью движка Stockfish.

Исходный код взят из репозитория [Eugenenoble2005/chesscheat](https://github.com/Eugenenoble2005/chesscheat) (автор: Eugenenoble2005). Шахматный движок — Stockfish.

### Автор

**sackedrai**

### Установка

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/sackedrai/chesscheat.git
   ```
2. Откройте `chrome://extensions` (Chrome) или `about:debugging` (Firefox).
3. Включите режим разработчика.
4. Нажмите «Загрузить распакованное» и выберите папку с репозиторием.
